# 流量模块 HTTPS 入口

依据 D24/D25 及用户继续实现 HTTPS 的指令，沿用本机统一精确域名策略。

1. 为请求提取域名增加边界用例：HTTP/HTTPS、CONNECT、IPv6、端口、无效输入。加入名单去重，保留其他域名。
2. 新建流量 HTTPS 控件，包含启停、名单编辑弹窗、请求右键菜单。菜单加入即启用；CA 缺失/过期、冲突、保存失败需明确提示且保留草稿。关闭解密不依赖 CA 可用。
3. 流式/目录式/单 IP 均接入菜单；选中详情随请求完成刷新，隧道正文说明不可解密历史记录。
4. 前端行为与浏览器回归、现有真实 TLS Go 集成测试、构建。更新验收手册并交付 Windows 程序，手机证书信任由用户实机确认。

界面：流量工具栏上方显示 HTTPS 状态、域名数量、启停与名单入口；菜单精确显示目标域名；保存后持续提示“重新连接后生效”。不增加全域名解密选项。
