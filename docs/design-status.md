## 2. 已确认且已同步

- Windows/macOS 桌面，Wails v2 + Go + Vue3/TypeScript + SQLite；内部前后端分层，共同打包。
- 同代理端口、来源 IP 区分设备；每设备独立选择三种模式与组运行。
- 每设备可选择一个独立规则集，规则集可被多设备复用；按列表顺序取首个启用命中规则。
- 随机列表采用单记录模板生成新条目，仅随机配置字段，其他字段保持模板值。
- 完整响应成功写入连接后才推进当前步骤；生成/写出失败均不推进。
- 组未命中及完成后真实转发，通用 Header 仍生效；不回退独立 Mock。
- 响应配置下一请求生效，在途保留版本；组顺序与步骤开关下次开始/重置生效。
- 切出组模式或改绑另一个组停止旧运行，手动开始；退出停止代理、重启不自动续跑。
- 2026-09-10 补充确认 D07：应用启动后不自动监听，需手动开启代理；设备选择恢复策略仍待确认。
- 2026-09-10 补充确认 D11：首版支持 Windows x64（Intel/AMD）、macOS Intel 和 Apple Silicon；Windows ARM64 不纳入首版。最低系统版本和分发细则仍待确认。
- AI 数据与规则 CRUD 保留，首版禁止切模式、绑定及运行开始/停止/重置。
