# 08 桌面页面与交互

日期：2026-09-10。四个一级模块已由用户明确；细节为评审建议。产品结构以 [四模块规划](../project-plan.md) 为准，原六工作区导航已替换。

## 1. 导航与公共入口

| 页面 | 主要操作 | 上下文 |
| --- | --- | --- |
| 设备管理 | 证书生成/下载、接入、IP/备注、绑定配置、查看设备流量 | 实际来源 IP、绑定项目、模式、规则集、设备独立运行 |
| 规则管理 | 接口规则、请求头/响应头、固定/随机编辑、样本和业务数据选择 | 查看项目、引用关系、已保存版本与草稿 |
| 规则集管理 | 优先匹配编排、原顺序 Mock 组编排、关联设备与运行详情 | 定义版本与选中设备的运行版本 |
| 流量 | 全部 IP/单 IP × 流式/目录式、筛选、详情、创建规则 | 独立流量筛选、来源 IP、请求当时项目、实际使用配置 |

沿用已选“功能导航 + 工作区”：左侧四模块，页面内列表与详情。公共栏提供代理启停、查看项目、应用设置；设置包含监听参数、存储和 AI 接入。证书统一在设备管理，通用 Header 统一在规则管理。

查看项目不改变设备绑定。流量独立项目筛选的默认全部项目建议见 D18；设备页始终明确实际绑定。应用启动不监听，用户手动开启；关闭窗口退出并停止代理。

## 2. 设备与规则编辑

新 IP 真实转发；IP 不是永久身份，不自动合并旧设备。显示最近活动，不能无依据声称实时在线。证书下载与安装信任分开提示；仅下载公共证书。

规则管理分接口规则与 Header 规则。JSON 编辑、匹配编辑、随机预览、样本/业务数据辅助面板在此复用；规则集页通过引用跳转编辑，不复制正文。预览标注草稿；保存后显示适用的生效说明；其他入口修改时保留本地草稿并显示版本冲突。

独立 Mock 启用、顺序步骤启用、捕获保存各自展示。现有独立启用是规则级影响，额外成员级开关待 D19。固定/随机切换细则待 D08，草稿恢复待 D16。

## 3. 规则集与运行

建议在一个模块内分优先匹配与顺序执行入口，后者承接原 Mock 组。前者显示优先顺序，后者显示步骤顺序，两种含义不可混用。是否保留顺序首版范围见 D17，本轮按原已确认能力继续保留。

顺序定义显示下次开始/重置生效的修改；运行区选择设备后显示本次顺序、当前步骤、运行状态及实际响应版本。开始/停止/重置调用同一后台命令；界面不自增游标。改绑或切出停止旧运行，新运行手动开始；在途细则待 D05。

## 4. 流量双维度

范围选择为全部 IP 或单 IP；展示选择为流式或目录式。两者独立，四种组合都能进入相同详情。建议默认全部 IP 流式；目录按协议/域名/端口、路径段、请求实例展开，具体聚合见 D18。

流式按开始时间追加，以稳定 ID 区分同时间请求；响应完成更新原条目。目录不把重复请求合为一条；相同路径不同 Query、方法、IP 的实例保留。筛选后计数与查询范围一致，两种视图切换保留筛选及选中记录。

详情区展示原始/修改后请求、实际响应、来源、命中原因、版本及错误。多值 Header 多行显示，正文按需读取；未保存、截断、未解密分别标识。自动滚动开关不停止网络或捕获，清空视图不等于删除持久记录。

从设备页跳转自动带入 IP；从流量创建规则带入所选请求，未绑定流量需明确目标项目；返回时保留筛选上下文。

## 5. 状态与组件建议

前端按 features/devices、rules、ruleSets、traffic 四模块组织。settings 是公共入口，catalog 是规则管理辅助组件；后台仍可保持独立场景、生成、证书、存储模块，不要求四个后端包。

复用 JsonEditor、HeaderOperationsEditor、MatcherEditor、ValidationList；事件批次通知、列表虚拟化、目录按需展开、正文按需加载。配置和运行状态以 Go 为准，前端只保留筛选、选择与草稿；重连查询快照。

## 6. 交互验收

设备接入 → 观察真实请求 → 创建接口规则 → 加入规则集 → 绑定设备 → 流量显示实际命中；两台设备可复用定义但运行进度独立。四种流量组合在同一筛选下包含相同请求；未绑定来源可发现；改绑不改写历史归属。代理失败、证书问题、空列表、无正文、生成失败、版本冲突、停止/重连均有明确反馈。
