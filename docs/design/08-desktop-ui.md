# 08 桌面页面与交互

实现建议：Vue 3 Composition API、script setup、TypeScript。页面数据以 Go 返回的已保存版本和运行状态为准，前端仅拥有筛选、选择与未保存草稿。

## 1. 导航与页面

| 页面 | 主要信息 | 核心操作 |
| --- | --- | --- |
| 设备接入 | 局域网地址/端口、证书步骤、IP、备注、最近活动、模式 | 选择三种模式、规则集/组、桌面运行控制 |
| 流量 | 时间、IP、方法/URL、状态、耗时、来源、命中原因 | 筛选、查看请求/响应、提取样本、创建 Mock |
| Mock 与规则集 | 规则集、顺序、启用、匹配条件、活动响应版本 | CRUD、重排、固定/随机编辑、预览 |
| 数据 | 抓包样本、业务数据集与记录 | 查询、编辑、选择记录构建响应 |
| Mock 组 | 步骤列表、启用开关、引用 Mock、设备运行进度 | 编辑组、选设备查看当前步、手动开始/停止/重置 |
| 设置与 AI 接入 | 监听、证书、本机 MCP 状态、数据策略、诊断 | 配置连接与查看错误；未确认设置不伪装成已实现 |

顶部显示代理是否监听及当前项目；若 D15 未决定多项目并行，不设计多个项目同时占同一设备的路由。

## 2. 设备配置

每台设备可选择一个独立规则集，规则集可被多设备复用，规则顺序属于规则集。切换到独立模式显示所选规则集；切换到组模式显示所选组、当前步骤、运行状态及开始按钮。

新 IP 首次出现显示真实转发；从旧 IP 复制标签或选择组必须用户主动执行，不能自动推断为旧手机。界面不把 NAT 后同 IP 的多个设备伪装成可独立绑定。

切出组模式/改绑其他组后的提示说明旧运行已停止、新运行需手动开始。UI 等后台确认状态后再更新运行按钮，禁止点击后在前端自增游标。

## 3. Mock 编辑

左侧匹配与响应模式，中间 JSON 编辑/字段树，右侧预览与校验问题。提供来源样本/业务记录选择器；来源只在编辑生成时使用。随机规则编辑采用字段选择与类型参数，避免要求用户掌握生成配置 JSON。

保存成功显示新的 revision 及“下一请求生效”；草稿预览始终标注“未保存”，不冒充手机实际收到的响应。收到另一入口修改事件时保留本地草稿，提示版本冲突并提供刷新/对比，不能静默覆盖。

独立启用、抓包保存、组步骤启用显示在各自上下文，并解释作用范围。尤其规则在独立模式被禁用时，引用它的启用组步骤仍可使用其响应。

列表来源已确认按一条业务记录模板生成新条目；固定/随机切换的内容选择待 D08，不在原型中做无法恢复的隐式转换。

## 4. 组编辑与运行视图

编辑区显示“组定义版本”；运行区显示“本次顺序版本、当前步骤、实际响应版本”。编辑组后提示顺序/步骤开关将在下次开始或重置采用；响应编辑则不要求重置。

每个步骤显示接口、固定/随机类型、有效状态。运行中当前步骤、成功步骤、跳过的禁用步骤必须视觉区分。未命中请求显示真实转发原因，不能为了画出完整流程而把提前请求标为已完成。

运行失败记录提供 requestId、步骤、错误类型、版本和实际写出状态；生成失败时保持同一步，提供跳转编辑入口。

## 5. 流量详情

请求区区分原始值与工具修改后的值，响应区展示实际写回内容及来源。多值 Header 按多行显示，JSON 大正文按需加载。实际未保存正文时显示“未保存”，不从当前模板重新生成历史内容。

按 IP、域名/路径、方法、状态、Mock/真实来源、组运行筛选。命中原因是后台结果，前端不再独立运行匹配算法。

## 6. 状态与组件建议

features/devices、traffic、mocks、catalog、scenarios、settings 各自拥有页面与局部组件。共享组件包括 JsonEditor、HeaderOperationsEditor、MatcherEditor、RevisionBadge、ValidationList。

composables 负责绑定调用与事件订阅；销毁时解除订阅；大流量采用批次和虚拟列表。选择状态与服务器对象分离，不因过滤流量列表丢失正在编辑的 Mock 草稿。

断线/停止时将运行控制设为不可用并解释原因，重连后查询快照；不从旧事件猜当前状态。未保存草稿恢复行为待 D16。

## 7. 交互验收

从流量提取样本并建立固定 Mock 可完成闭环；选择业务记录构建随机响应可预览并保存；同规则集被两设备复用但组进度不共享；AI 修改触发版本提示；关闭窗口确实退出；无正文记录和未解密隧道均有明确说明。
