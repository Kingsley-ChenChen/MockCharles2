# 流量模块规格

状态：详细设计草案。全部 IP/单 IP × 流式/目录式、仅目录式导出、首版不导入、重启不恢复上次流量已确认。D18 目录具体层级与默认范围、D09 容量及敏感内容处理仍需收口。

关联功能：[TRA-01 与 TRA-02](../../functional-analysis.md)。本模块共用 [05 存储设计](../05-storage-versioning.md)，不复制规则引擎的判定逻辑。

## 1. 三种数据生命周期

| 数据 | 生命周期 | 退出/重启行为 |
| --- | --- | --- |
| 本次会话流量 | 从本次接入代理产生，到清理或会话结束 | 重启不展示上次流量；不建立自动历史浏览功能 |
| 主动导出文件 | 用户明确从目录式导出到外部路径 | 文件保留；首版应用不提供导入/打开此文件恢复会话 |
| 已提取样本和已保存规则 | 独立配置数据，拥有自己的内容快照 | 正常持久保存，不依赖原流量仍存在 |

临时落盘仅是控制内存的实现选择，不等于永久历史。若采用临时文件，应按会话隔离，正常退出清理，启动清理未正常退出的旧缓存；不因磁盘上仍有缓存就自动恢复旧请求。具体缓存容量与清理实现须在 D09 资源策略中固定。

当前决定替代早期“持久录制以便重启查看”的候选方案。是否保留有限执行诊断元数据与正文分开设计，不能绕过“不自动保留历史”偷偷保存可恢复的完整请求。

## 2. 流量对象草案

| 字段 | 类型与含义 | 不变量 |
| --- | --- | --- |
| sessionId / flowId | 稳定 ID | 请求开始分配，完成不新建第二条 |
| sourceIp | 规范化 IP | 来自连接，不从可伪造 Header 取值 |
| projectId | ID 或 null | 请求时归属；未绑定为 null；改绑不重写本条 |
| bindingRevision | 整数或 null | 本次路由所用绑定版本 |
| startedAt / finishedAt | UTC 时间，完成时间可空 | 时间相同仍以 flowId 区分 |
| state | pending/completed/failed/cancelled | 核心更新，生成成功不等于写出成功 |
| method / scheme / host / port / path / query | 实际请求地址部分 | Query 保留重复项，不把同路径请求合并成一条 |
| status / duration / sizes | 可空摘要 | 未完成没有状态码时不虚构 200 |
| route / routeReason | 真实/固定 Mock/随机 Mock 及原因 | 来自实际计划，不用当前规则重新推断 |
| ruleId / setId / runId / stepId | 可空关联 | 保存本次实际使用对象 |
| responseRevision / headerRevisions | 实际版本信息 | 历史正文不根据新版本重建 |
| requestBody / responseBody | 引用与 available/not_captured/truncated/encrypted/unavailable 状态 | 大正文不随列表批量传输；不可用原因明确 |

原始与改写后的 Header 均保留多值表示。路由为完整 Mock 时改写后的请求可解释为计划值，不声称发到了上游。

## 3. 共用查询与两个展示方式

查询对象建议为 sessionId、sourceIp（可空表示全部）、projectFilter（all/unbound/projectId）、时间范围、方法、域名/路径、状态、响应来源、cursor、limit。

流式和目录式复用同一个过滤器。目录节点只是一种分组，不拥有独立流量副本。建议层级为协议+主机+端口 → 路径段 → 请求实例；具体层级及默认全部项目见 D18，未确认前原型标注建议。

| 查询 | 输入 | 输出与约束 |
| --- | --- | --- |
| traffic.list | 共用过滤器、游标、上限 | 摘要页、nextCursor；稳定排序，不重复/跳过同时间实例 |
| traffic.tree | 共用过滤器、父节点、游标、上限 | 子节点/实例、匹配计数、nextCursor；计数不是已加载列表页大小 |
| traffic.get | sessionId、flowId | 详情与正文状态；记录已清理返回明确不存在 |
| traffic.readBody | sessionId、flowId、方向 | 正文或缺失/截断等状态；不自动重新请求上游 |

查看全部 IP 时实例仍显示 IP；查看单 IP 时不混入其他来源。切换视图保留筛选和选中 flowId，若记录已清理则提示不可用。目录折叠、自动滚动开关、查看项目切换都不能影响设备执行。

批次事件包含新增/完成摘要及会话序号；发现缺口重新查询。完成更新不能被新请求追加淹没而永远显示 pending。列表虚拟化、目录按需展开、正文按需读取控制 UI 负载。

## 4. 导出：已确认入口与待评审细则

仅目录式显示导出入口；全部 IP 的目录式和单 IP 的目录式均可导出。流式视图无导出按钮，首版无导入能力。后端不依赖一个可伪造的“当前 UI 模式”做权限判断，此限制是产品入口行为。

建议导出流程：选中目录节点或当前查询范围 → 显示范围和条数 → 选择路径 → 导出 → 显示结果。节点/整范围、多选以及格式属于 D13 的下一步设计，不擅自固定为用户确认。

拟定内部命令 `traffic.export` 接收 sessionId、查询范围/节点、格式与受控保存目标；返回实际文件位置、数量、缺失正文统计。实现时通过桌面保存对话框选择路径，不允许文件名来自未经处理的 URL。

导出应在开始时固定候选 flowId 范围，避免持续到来的流量让导出永不结束；未完成请求、正文已清理或截断必须在结果中说明，不能静默补造内容。导出失败保留原会话，不呈现部分文件为完整成功。建议临时文件写完后原子替换，用户覆盖已有文件由保存对话框明确处理。

格式建议将在 D13 提交：标准交换格式方便外部工具查看，自定义 JSON 更容易完整携带规则/版本元数据；未验证前不承诺 Charles 私有会话格式兼容。

## 5. 缓存与清理

已确认重启不恢复会话；仍需确定最大摘要条数、正文总量、单正文上限、清理顺序以及用户可见提示。不无限缓存；达到上限时必须明确哪些记录/正文不可再查看或导出。

自动滚动只影响滚动跟随。清空视图与清理本次会话数据需要明确的按钮名称和范围；不能一个不明含义的“清空”误删已保存样本/规则或外部导出文件。

## 6. 验收路径

两 IP 产生相同路径但不同方法/Query 的请求；在全部 IP 流式与目录式观察相同实例集合，切单 IP 后只剩该来源。请求完成更新原记录，选中详情仍一致。

目录式可进入导出，流式不提供该入口，无导入入口。已导出文件和已提取样本在退出后存在；重新启动不显示上次会话流量。改绑不重写本会话旧记录的项目字段。无正文、仅隧道、超限截断分别解释，不以模板重新生成历史内容。

正式导出文件解析、容量边界和多平台保存对话框用例，在格式/资源策略确认及实现后完成；本规格不宣称已有测试通过。

## 7. HTTPS 解密入口迁移（2026-09-12，已实现）

- HTTPS 解密启停及域名范围管理属于流量模块；设备页仅保留 CA 生成、公共证书下载与安装指引。
- 全部 IP / 单 IP、流式 / 目录式中的每条请求实例支持右键菜单，提供“当前域名解密”。CONNECT 仅隧道记录也应能使用该入口。
- 操作从该条请求的 URL/CONNECT authority 解析当前域名或 IP，加入既有精确解密名单，不将方法、路径、Query 或端口作为域名保存。不改变设备所属项目或启用规则集。
- 保留 D24 的本机统一解密范围，名单外只转发隧道；对新连接生效，不重新解密历史流量。实现时应明确提示重新连接。
- CA 未就绪或过期时提示前往设备页生成并安装；无有效域名时禁用菜单。启停与名单入口位于流量工具栏上方，失败显示错误，成功明确提示重新连接。
- 已接入流量页解密状态、启停、名单弹窗及右键菜单。菜单加入即启用，重复启用项禁用；保存失败保留草稿，配置冲突要求显式重新加载。关闭解密无需有效 CA。
