## HTTPS 实现决定（2026-09-11）

D24 已确认：指定域名解密；名单外 HTTPS 仅建立加密隧道，名单内才进入 Header/Mock/正文捕获。当前实现以精确域名或 IP 列表作用于本机代理全部设备，不与查看项目或设备启用规则集联动。修改解密设置对新 CONNECT 连接生效，已有连接需重连，界面在保存时提示。

D21 本阶段实现：设备页手动生成本机 CA；重复生成返回已有证书，不重建。公共证书可通过本机保存对话框导出，或手机配置代理后访问 `http://mockcharles.invalid/ca.crt` 下载。私钥以 Windows 当前用户 DPAPI 加密保存，其他平台使用受限文件权限。本阶段不提供 CA 重建、自动安装系统信任或私钥导出；重建影响和恢复策略仍待后续产品决定。

D25 已确认（2026-09-12）：HTTPS 解密启用和域名管理移至流量模块。每条请求可右键选择“当前域名解密”，包含只显示 CONNECT 的隧道请求。本次先删除设备页开关/名单/保存控件，记录为流量模块待办；证书生成、下载与安装指引仍在设备页。后端能力和已存解密配置保留。D24 的精确域名范围不变。

D26 已确认（2026-09-12）：配置阶段下载证书不依赖正式抓包。打开安装指引自动准备同端口的证书专用服务；不记录流量、不发现设备、不应用 Header/Mock，不向其他目标转发。开始抓包切换为完整代理，停止后恢复已准备的证书服务；退出软件释放端口。端口占用在指引中明确报错。首次进入配置时无需点击“开启代理”。

D27 已确认（2026-09-12）：新生成的本机 CA 以生成时的本机时间命名（精确到秒，带时区，格式 YYYY-MM-DD_HH-mm-ss+0800），公共下载与桌面保存使用同名 .crt。有效期从 NotBefore 起一个日历年，保留起始时间回退 5 分钟的时钟容差。已生成证书继续复用，不自动修改或替换；旧证书名称、有效期和下载文件名保持原样。

D28 已确认（2026-09-12）：目录采用 A 紧凑树形方案。域名/路径配层级线和计数，每次请求独立保留，方法、状态、耗时、时间分列；CONNECT 独立放入默认折叠的“加密隧道”分组。隧道尽可能展示目标域名和端口、来源 IP、时间、耗时、状态与错误；CONNECT 无法获得加密正文中的路径，必须标明“路径不可见”，不虚构根路径。解密请求按真实路径分组并显示 Query。

D29（2026-09-12）：用户要求根域名范围或 regex，并要求域名编辑器搜索高亮和匹配数量。本次采用显式 *.baidu.com 覆盖根域名及任意层子域名；普通 baidu.com 仍为精确匹配，旧配置不自动扩大。不提供 regex、全局 * 或 IP 通配符。菜单识别已被范围覆盖的域名。搜索使用不区分大小写的字面匹配，保留完整原文，显示匹配次数及当前位置，支持上一个/下一个。
