# 06 固定响应与随机生成

已确认首版两种响应模式；随机配置每次请求执行，不保证连续结果一定不同。随机字段范围与列表长度可配置，未配置字段保留模板值，跨接口标识固定填写。

## 1. 编辑流程

选择抓包样本或业务记录 → 映射/编辑目标 JSON → 选择固定或随机 → 校验 → 预览 → 保存完整响应版本。

源数据仅在编辑阶段读取。D02 已确认：编辑时选一条业务记录作为列表项模板，请求时按数量生成新条目，只随机指定字段，其余保留模板值。首版不提供从记录池抽样模式，不在运行时通过 datasetId 拉取可变业务记录。

固定模式直接使用保存正文，仍应用 Header 与 HTTP 正文规则。随机模式基于保存模板填充指定字段。固定/随机切换时冻结哪次结果待 D08，不悄悄选最近随机结果覆盖编辑内容。

## 2. 生成定义草案

下面是已确认模板合成方式的配置结构建议；不是 MCP 标准或已实现接口。

```json
{
  "mode": "random",
  "status": 200,
  "template": { "code": 0, "orderId": "O-FIXED-001", "items": [] },
  "generation": {
    "arrays": [{
      "pointer": "/items",
      "count": { "min": 2, "max": 5 },
      "itemTemplate": { "id": "", "price": 0, "state": "", "enabled": true },
      "fields": [
        { "pointer": "/id", "type": "uniqueId", "scope": "response" },
        { "pointer": "/price", "type": "decimal", "min": 1, "max": 99, "scale": 2 },
        { "pointer": "/state", "type": "enum", "values": ["new", "ready"] },
        { "pointer": "/enabled", "type": "boolean" }
      ]
    }]
  }
}
```

同一响应唯一性通过单次生成上下文中的集合/无重复分配实现，不靠无限碰撞重试。若不同字段共享同一唯一域，需明确唯一域名称；类型转换后的碰撞同样视为冲突。

## 3. 首版能力与校验

| 能力 | 已确认范围 | 实现校验建议 |
| --- | --- | --- |
| 列表长度 | 固定值或范围 | 非负整数，min ≤ max，最大输出预算 |
| 整数 | 范围 | 边界可表示，避免前端大整数精度丢失 |
| 小数 | 范围与精度 | 推荐按最小精度单位抽取，避免二进制浮点越界 |
| 枚举 | 候选值 | 非空、类型明确，重复值是否影响概率需规定 |
| 字符串 | 随机字符串 | 长度/字符集/内置格式按 D08 确认 |
| 布尔 | true/false | 概率配置是否暴露待 D08 |
| 嵌套对象/列表项 | 字段定位 | 路径存在、父节点类型正确，避免父子规则互相覆盖 |
| 唯一 ID | 单响应唯一 | 可选空间不足直接失败，不无限重试 |

输出字节上限、最大数组数量和嵌套层级是必要资源保护参数，具体数值通过 D12 和实验确定。超限返回明确生成错误，不悄悄截断列表后伪装满足配置。

## 4. 生成器接口与执行

Validate(spec) 返回字段级问题；Compile(spec) 返回只读计划；Generate(plan, context) 返回 body/status/headers、generationId、可选诊断 seed。

单次 context 包含请求生成标识、独立随机源、唯一值集合及资源预算，不含可修改运行游标。不同 IP 不共享唯一值集合或可变随机计数。生成器不执行任意用户脚本，不连接真实数据库或网络。

顺序建议：复制模板 → 确定数组数量 → 生成条目 → 填写字段 → 检查唯一性/类型 → 序列化并验证预算。若支持嵌套列表，编译时确定父子依赖顺序并拒绝循环/冲突规则。

seed 可用于测试和诊断，但用户是否可固定 seed 属于后续交互决定。重现结果还需要记录生成器版本与配置版本，仅 seed 不足以跨算法升级保证一致。

## 5. 失败与预览

保存阻止明显无效活动配置；合法配置仍可能因预算、资源或组合约束在运行时失败。失败不真实转发、不推进当前组步骤。建议手机错误 JSON 包含 code=MOCK_GENERATION_FAILED、requestId 与可读原因；HTTP 状态建议 500，作为技术契约评审项。

预览调用相同生成器但使用独立上下文，不消耗运行步骤，不改变下次请求的随机上下文。编辑后显示“预览对应草稿”，保存后显示活动版本；二者不能混淆。

## 6. 验收

多次生成均满足长度/范围/类型，允许自然重复；同响应 ID 不重复；不可满足唯一空间明确失败；嵌套规则按路径生效；业务记录被修改后已保存模板不变；预览不推进；失败后修正保存，原步骤重试读取新版本。
